3.1. Testing Mock Backend Service Layer (services/history_service.py)
--------------------------------------------------------------------------------
File 1: services/history_service.py
File 2: services/_history_data.json

Purpose:
Validates that the HTTP REST microservice starts correctly, binds to port 8083,
parses the mock JSON database, and responds to HTTP requests without dependencies.

Step 1: Start the service in Terminal 1
  python services/history_service.py --port 8083

  Expected Terminal Output:
  Resident History API on http://127.0.0.1:8083  (12 residents)

Step 2: Test Health Endpoint (in Terminal 2 or PowerShell/cmd)
  python -c "import urllib.request; print(urllib.request.urlopen('http://127.0.0.1:8083/health').read().decode())"

  Expected Output:
  {"status": "ok", "service": "resident-history", "records": 12}

Step 3: Test Resident History Profile Endpoint (R-20500)
  python -c "import urllib.request; print(urllib.request.urlopen('http://127.0.0.1:8083/residents/R-20500').read().decode())"

  Expected Output:
  JSON object containing resident reference R-20500, district 'Ash Hill', award 988.04, household, and events.

Step 4: Test Household Sub-Endpoint (R-20500)
  python -c "import urllib.request; print(urllib.request.urlopen('http://127.0.0.1:8083/residents/R-20500/household').read().decode())"

Step 5: Test Non-Existent Resident Endpoint (404 Handling)
  python -c "import urllib.request, urllib.error; getattr(urllib.error, 'HTTPError'); print(urllib.request.urlopen('http://127.0.0.1:8083/residents/INVALID-999').read().decode())"

  Expected Output:
  HTTP 404 response payload: {"error": "not_found", "resident_ref": "INVALID-999"}

3.4. Testing Policy Guardrail Interceptor Engine (src/guardrail.py)
--------------------------------------------------------------------------------
File: src/guardrail.py (PolicyGuardrailEngine)

Purpose:
Verifies the deterministic interception logic across all three evaluation paths:
1. Permitted adult-only triage proposal (Sec 2.4)
2. Supervisor escalation for prohibited mutations (Sec 3.1 - 3.8)
3. Caseworker hand-off for minor safeguarding (Sec 3.9) or missing household data (Sec 5.2/6.1)

Command 1: Test Permitted Adult Referral Evaluation
  python -c "from src.guardrail import PolicyGuardrailEngine; e = PolicyGuardrailEngine(); ref = {'requested_action': 'Review award', 'summary': 'Routine review'}; hist = {'household': [{'date_of_birth': '1985-01-01'}]}; d = e.evaluate(ref, hist); print('Permitted:', d.is_permitted, '| Clause:', d.clause)"

  Expected Output:
  Permitted: True | Clause: Section 2.4

Command 2: Test Section 3.2 Award Suspension Interception (Supervisor Escalation)
  python -c "from src.guardrail import PolicyGuardrailEngine; e = PolicyGuardrailEngine(); ref = {'requested_action': 'Suspend assistance pending investigation', 'summary': 'Fraud report'}; hist = {'household': [{'date_of_birth': '1985-01-01'}]}; d = e.evaluate(ref, hist); print('Escalation:', d.requires_escalation, '| Clause:', d.clause)"

  Expected Output:
  Escalation: True | Clause: Section 3.2

Command 3: Test Section 3.4 Payment Details Interception (Supervisor Escalation)
  python -c "from src.guardrail import PolicyGuardrailEngine; e = PolicyGuardrailEngine(); ref = {'requested_action': 'Update payment details', 'summary': 'Bank change'}; hist = {'household': [{'date_of_birth': '1985-01-01'}]}; d = e.evaluate(ref, hist); print('Escalation:', d.requires_escalation, '| Clause:', d.clause)"

  Expected Output:
  Escalation: True | Clause: Section 3.4

Command 4: Test Section 3.9 Minor Safeguarding Interception (Caseworker Hand-off)
  python -c "from src.guardrail import PolicyGuardrailEngine; e = PolicyGuardrailEngine(); ref = {'requested_action': 'Review award', 'summary': 'Child in house'}; hist = {'household': [{'name': 'Child', 'date_of_birth': '2020-05-01'}]}; d = e.evaluate(ref, hist); print('Hand-off:', d.is_handoff, '| Clause:', d.clause)"

  Expected Output:
  Hand-off: True | Clause: Section 3.9

Command 5: Test Missing Household Composition Fallback (Sec 5.2/6.1 Hand-off)
  python -c "from src.guardrail import PolicyGuardrailEngine; e = PolicyGuardrailEngine(); ref = {'requested_action': 'Review award', 'summary': 'Address check'}; d = e.evaluate(ref, None); print('Hand-off:', d.is_handoff, '| Clause:', d.clause)"

  Expected Output:
  Hand-off: True | Clause: Section 3.9 (via 5.2 / 6.1)
